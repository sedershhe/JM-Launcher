> 前提：PlainToolkit.UI 自述“extracted from **PCL2-CE**”，且“**Zero custom controls** — Pure XAML styles”（`PlainToolkit.UI-main/README.md:4`、`:28`）。PCL2 主线的 `My*` 控件几乎都是 VB 自定义控件（`MyCard.vb`、`MyListItem.xaml.vb`、`MyDropShadow.vb`…），二者的观感基线不同，所以差距不是“少几个样式”，而是“两套设计语言”。

## G. JML 落地建议

### G1. 哪些直接照搬（纯参数，风险低）

1. **色板**：PlainToolkit 的 `Colors.xaml` 与 PCL2 的色值**完全一致**（`PlainToolkit/Themes/Colors.xaml:10-20` vs `Application.xaml:22-31`），无需自建色表；只要**切回浅色**即可拿到 PCL2 的默认配色。
2. **字号阶梯**：13 正文 / 14 左栏项 / 12 分组标题（`Opacity=0.6`）/ 15 内页标题 / 16 主按钮 / 19 空状态；`TextTrimming=CharacterEllipsis` 全局打开。JML 现用的 15（页内标题）与 13 混排可直接映射。
3. **间距语法**：页面外边距 25（`PageDownloadInstall.xaml:10` 等）；卡片间距 12~15；卡片内容 20,40,18,15 或 25,40,25,15；按钮行高 35、按钮间距 20、`MinWidth=140`；组标题 `Margin=13,20,5,4`。

### G3. 做不到 / 不建议照搬

| 项 | 原因 |
| --- | --- |
| `MyDropShadow` 的像素级锐利阴影 | 需要 `OnRender` 九宫格渐变自绘（`MyDropShadow.vb`）；`DropShadowEffect` 是高斯模糊，永远“发虚”。可接受降级：`BlurRadius=3~4, ShadowDepth=1, Opacity=0.07`。 |
| 窗口入场“旋转 −4° + 下落 60”动画 | 技术上可做（`RotateTransform`/`TranslateTransform` + `EaseOutBack`），但 PCL2 用的是自研缓动与全局 `AniSpeed` 倍率；且透明窗大面积动画在低端机掉帧。建议**不做**，只保留淡入。 |
| 逐控件递进入场动画 | 依赖 `MyPageRight` 遍历可视树并给每个控件挂动画（`MyPageRight.vb`）。纯 XAML 做不到“整棵子树错峰”，要写代码遍历；投入产出比低。 |
| PCL 的 logo 路径 / 各图标 Path Data | 属 PCL 美术资产（`FormMain.xaml:117` 及各类目 200~1000 字符的 Data）。**参数可抄**（39×17、`StrokeThickness=2.2`、白色描边），**图形内容不要抄**；JML 应自备 “JML” 字形 Path 或图标字体。 |
| 内嵌字体 `PCL English` | PCL 自带 `Resources/Font.ttf`，不可随 JML 分发。回退 `Microsoft YaHei UI`。 |
| PCL2 的“无最大化” | 属产品取舍（`FormMain.xaml.vb:643`）。JML 若保留最大化会破坏自绘圆角（最大化时圆角贴边会露透明缝），建议与 PCL2 一致：只允许最小化 + 拖拽缩放。 |

### G4. 如果只能改 3 件事（按性价比排序）

1. **切回浅色主题 + 标题栏改纯蓝**（半小时内，观感变化最大）

2. **自绘窗口外壳**：去掉系统标题栏（`WindowStyle=None` + `AllowsTransparency=True` + `Background=null`），外层 `Margin=10` + 内层 `Margin=8`（合计 18 的透明边给阴影），内层 `Border` 加 `Clip` 圆角 6，48 高蓝色标题栏 + 左 logo + 居中导航 + 右三个 28px 圆形按钮，`PanTitle` 上挂 `DragMove`。这是“壳”像不像的决定项，也是当前与 PCL2 差距最刺眼的一处（现在仍是 Windows 原生白/黑标题栏）。
3. **顶部导航胶囊化 + 补图标**：把 `JmlControls.xaml:20-54` 的 `NavRadioButton` 改为 27 高、圆角 13.5、`Path 16×16` + 文字、悬停白 20%、选中纯白底 + `ColorBrush3` 前景；同时把左栏选中条从 3×16 改成 5×(高−12)（`JmlControls.xaml:74-80`）。
