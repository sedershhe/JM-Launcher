## 一、运行要求

1. **Windows 10 / 11（64 位）**。
2. **.NET 10 桌面运行时（x64）**：
   - 默认发布为**框架依赖**版，压缩包约 1 MB，但用户必须先安装
     [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)；
   - 如需免装运行时，可执行 `scripts\publish-portable.ps1 -SelfContained`，
     体积会明显增大，但**仍然需要 Python**（见下条）。
3. **Python 3.11 ~ 3.15（64 位）**：
   - 安装时勾选 `Add python.exe to PATH`；
   - 若 Python 装在非标准位置，设置环境变量 `JML_PYTHON_HOME` 指向其安装目录；
   - C# 侧按 `JML_PYTHON_HOME` → `PATH` → `%LOCALAPPDATA%\Programs\Python` →
     `Program Files` → 注册表 `PythonCore` 的顺序探测，不硬编码盘符。
4. **Python 依赖**：在程序目录执行
   ```bat
   python -m pip install -r requirements.txt
   ```
   依赖清单：`jmcomic`、`Pillow`、`PyYAML`、`curl_cffi`、`pycryptodome`。

> 取舍说明：没有把 Python 运行时打进包。Python 由用户自行安装、依赖可升级，
> 打包解释器会显著增大体积并引入版本锁定问题；界面的环境检测页会明确提示缺什么、怎么装。

---

## 二、首次启动步骤

1. 解压 ZIP 到任意目录（例如 `D:\JML`）。程序不会写入安装目录。
2. 安装 .NET 10 桌面运行时（框架依赖版）与 Python 3.11~3.15（64 位）。
3. 在程序目录执行 `python -m pip install -r requirements.txt`。
4. 运行 `JML.exe`：
   - 未签名程序首次运行会被 SmartScreen 拦截，见第六节；
   - 程序先做 Python 环境检测，缺依赖时给出安装指引；
   - 检测通过后进入主界面（PCL2 风格浅色外壳）。
5. 需要登录时，在账号窗口输入账号；凭据优先保存到 Windows 凭据管理器，
   不可用时才落 `%APPDATA%\JML\account.dat`（DPAPI 密文，绝不明文）。
6. 插件功能页在“插件”页中；停用/启用插件后**重启程序**才真正生效。

## 三、数据目录

程序只写用户目录，安装目录保持只读：

| 路径 | 内容 |
|---|---|
| `%APPDATA%\JML\settings.json` | 主设置（下载目录、旧版禁用列表迁移字段） |
| `%APPDATA%\JML\plugins\<id>\config.json` | 插件设置（password 类型不落盘） |
| `%APPDATA%\JML\plugins\disabled.json` | 已停用插件 id，**唯一真源** |
| `%APPDATA%\JML\account.dat` | 凭据管理器不可用时的 DPAPI 密文 |
| `%LOCALAPPDATA%\JML\data\` | 运行数据 |
| `%LOCALAPPDATA%\JML\logs\` | 诊断日志与自检日志 |
| `%LOCALAPPDATA%\JML\cache\` | 缓存 |
| `%LOCALAPPDATA%\JML\tmp\` | 下载临时目录 |

卸载：删除程序目录；如需彻底清理，再手动删除上述两个 `JML` 目录。
发布包**不包含**以上任何用户数据。

## 四、内置插件（4 个）

| 插件 id | 名称 | 功能 | 依赖 |
|---|---|---|---|
| `download_history` | 下载历史 | 记录每次下载的时间、本子号、成功/失败与输出路径；保留条数可配置 | 无 |
| `favorites` | 收藏夹 | 浏览当前登录账号的收藏夹，切换目录与排序，行内详情/下载 | `jm.session/1` |
| `zip_browser` | ZIP 浏览 | 选择文件夹列出 ZIP，包内翻页看图（不解压落盘） | 无；**提供** `archive_reader/1` |
| `zip_web` | ZIP 网页浏览 | 在本机回环地址启动 HTTP 服务，用外部浏览器纵向连续阅读；可停止并释放端口 | `archive_reader/1` |

插件停用/启用的真源是 Python 侧 `disabled.json`：bootstrap 返回的 `loaded`
已排除停用插件，C# 界面不再二次过滤。

## 五、无界面自检

```powershell
# 在程序目录执行
$p = Start-Process .\JML.exe -ArgumentList '--selfcheck' -Wait -PassThru
$p.ExitCode
```

- 退出码：`0` = 全部通过；`1` = 存在失败项。
- 每项输出 `OK` / `FAIL` 与一行原因；完整文本同时写入
  `%LOCALAPPDATA%\JML\logs\selfcheck-<时间戳>.log`。
- `JML.exe` 是 WinExe，直接双击或直接在 cmd 运行可能看不到控制台输出，
  以退出码和日志文件为准；用 `Start-Process -Wait` 或 `cmd /c "JML.exe --selfcheck & echo %ERRORLEVEL%"` 可稳定取码。
- 自检项：
  1. Python 运行时（版本 / DLL 路径）；
  2. Python 依赖库（复用 `PythonRuntime.Inspect` 实测）；
  3. 插件扫描（目录、manifest、坏插件）；
  4. 插件装配（loaded / failed / 停用）；
  5. 服务注册表快照（`jm.search`、`jm.detail`、`jm.download`、`jm.account`、
     `jm.session` + 插件提供的 `archive_reader`）；
  6. 配置契约（插件设置 schema + 主设置 `settings.json` 能否解析）。
- 自检**不创建主窗口**，不会进入界面。

## 六、SmartScreen 与代码签名

当前发布包中的 `JML.exe` **未做代码签名**。首次运行时 Windows 可能提示：

> Windows 已保护你的电脑

这是 SmartScreen 对“未知发布者”的常规提示，不代表检测到病毒。继续运行：

1. 点击提示框的 **“更多信息”**；
2. 点击 **“仍要运行”**。

如需彻底消除提示：使用受信任的代码签名证书（如 EV 证书）对 `JML.exe` 签名，
或在企业环境通过组策略/Intune 下发信任规则。发布脚本不会自动签名，签名口令
不得写入仓库或脚本。

## 七、发布脚本

```powershell
# 默认：框架依赖版，输出 dist\JML-portable-<版本>-<日期>.zip
pwsh -File scripts\publish-portable.ps1

# 可选：自包含版（免装 .NET 运行时，体积更大）
pwsh -File scripts\publish-portable.ps1 -SelfContained

# 可选：指定版本 / 产物目录
pwsh -File scripts\publish-portable.ps1 -Version 1.0.0 -DistRoot D:\release
```

脚本行为：

- `dotnet publish -c Release -r win-x64 --self-contained false -o <stage>`；
- 复制 `Python\` 源码（排除 `tests/`、`__pycache__`、`*.pyc`）与 `plugins\` 全部插件；
- 生成 `README.txt`（运行要求 / 数据目录 / SmartScreen / 自检）；
- 打包前校验必需文件，并拒绝把 `settings.json`、`account.dat`、`disabled.json`、
  `config.json`、日志、`Draw/`、`Delete/`、`__pycache__` 等打进包；
- 只清理 `dist\JML-portable-*` 自身产物，不碰源码与用户数据；可重复执行。

## 八、已知限制（验收口径，不作为缺陷重报）

1. **页数补全 3 秒封顶**：搜索结果的真实页数按需补全（并发 3、总等待 3 秒），
   补不到时显示“页数: -”；jmcomic 2.7.1 的 `page_count` 恒为 0，真实值取
   `total_photos` 白名单字段。
2. **详情窗仍用系统标题栏**：主窗口是 PCL2 风格无边框自绘标题栏，详情窗仍是
   系统边框，视觉不完全统一。
3. **插件热切换不生效**：停用/启用只改持久化状态，需要重启程序才重新装配。
4. **Python 不随包分发**：首次运行必须自行安装 Python 与依赖（详见第一节）。
5. **未签名**：见第六节 SmartScreen。
6. 旧内容切页使用整层 70ms 淡出，未做逐控件 stagger 动效。
