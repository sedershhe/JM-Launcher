## 阻断项（必须先修）

```
Navigation\NavigationStack.cs(70,72): error CS0037
无法将 null 转换为“(string PageId, string Title)”，因为后者是不可为 null 的值类型
```

第 70 行：`popped = _innerStack.Count > 0 && _innerStack.Pop() is not null;`

值元组是值类型，不能与 `null` 比较。修复：以 `Count > 0` 判定，再执行 `Pop()`。

**不修则 `dotnet build` 失败，阶段 1 无法推进。**

## 两个易踩的坑（已实测确认）

1. **插件入口函数必须叫 `setup(ctx)`**，
   不是 `build` / `main`。写错会得到清晰报错（不会崩溃，但插件不加载）。
2. **`emit_test_event` 的 payload 必须自带 `type` 字段**，且值等于第一个参数
   （"禁止裸 dict"校验）。建议后续由 `EventRelay` 统一补该字段。
