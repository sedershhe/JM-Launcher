### 复核发现并修掉的真实缺陷（摘要）

1. **状态提交晚于终态事件**：C# 在 `batch_finished` 里查状态会得到 `running`。改为 commit → emit，并补"事件内查状态必须 finished"的用例。
2. **0 字节占位 ZIP 会留在用户下载目录**：改为 `.part` + `os.replace`，失败/取消同时清理 `.part` 与 0 字节产物。
3. **编号校验三份实现且规则不一致**：`start_download('["abc"]')` 曾返回 `ok:true` 并真的去请求 jmcomic。收敛为一份 `normalize_ids(digits_only=True)`。
4. **搜索快照两套所有者**：主界面与插件翻页会互相串页。收敛为按 `session_key`（`main` / `plugin:<id>`）隔离。
5. **jmcomic 自带 logger 直打 stdout**（URL/异常原文未脱敏，违反 AGENTS.md 红线）：接管 handler，WARNING+ 转 `download.log` 事件，INFO 只进诊断。
6. **全局并发只按批次生效**：两批并行会到 6 本。改为模块级信号量，全进程合计 ≤3。
7. **`validate_zip` 宽 except**：`MemoryError` 曾被判成 `IMAGE_INVALID`，加密 ZIP 的 `RuntimeError` 会逃逸。
8. **诊断只有写没有读**：新增 `get_diagnostics(limit)`，并写进契约 §九（C# 启动时必须 `set_log_dir`）。
9. **`bootstrap` 在全局锁内装配**：期间 UI 线程 `set_event_sink` 被阻塞数秒；且失败结果曾永久缓存不可重试。

## 三、关键设计决策（供后续阶段遵守）

| 决策 | 理由 |
|---|---|
| C# 只认 `error_code`，不解析中文文案 | 旧缺陷 #2：曾按消息关键词猜错误类型 |
| 所有入口返回 JSON 字符串，唯一例外 `fetch_cover` 返回 bytes | 一条铁律：跨语言只走 DTO，Python 对象不漏到 UI |
| `start_download` 立即返回，进度全靠事件 | 下载在 Python 后台线程 + 线程池，C# 不得同步等待 |
| 工作目录由调用方经 `work_dir` 传入 | C# 应传 `%LOCALAPPDATA%\JML\tmp`，避免临时文件污染用户下载夹 |
| 插件只通过 `PluginContext` 交互，新增 `call_service` | 旧缺陷 #9：插件摸宿主私有属性 |
| 事件总线下沉到 `jml/events.py` | 消除 core → host 反向依赖，`import jml.core.*` 不再顺带拉起插件宿主 |
| 每个批次保留最近 50 条历史 | `_BATCHES` 曾只增不删，长跑会累积 items |
