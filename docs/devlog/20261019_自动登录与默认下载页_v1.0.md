# 自动登录与默认下载页（2026-10-19）

## 目标

用户验收第一轮列表改造后提出两个小改动：

1. 第一次打开并登录成功后，后续启动自动登录，不再需要手动点击「使用已保存账号登录」；
2. 进入主界面默认展示的页面从「插件」改为「下载」。

用户确认：手动「登出」后，下次启动仍允许自动登录（只看本地是否有已保存凭据）。

## 实现

### 1. 默认页改为下载

- `Navigation/NavigationStack.cs`：`Current` 默认值 `MainPage.Plugin` → `MainPage.Download`。
- `MainWindow.xaml.cs` 的 `ShowMain()`：
  - 选中顶部 `NavDownload`；
  - `_nav.Navigate(MainPage.Download)`；
  - 保留原有 `UpdateContent()`。

### 2. 启动自动登录

- `Pages/SettingsPage.xaml.cs`：
  - 新增 `_autoLoginTask`：整个进程只执行一次；
  - 新增 `EnsureAutoLoginAsync()` / `AutoLoginAsync()`：
    - 先 `CredentialStore.Exists()`，没有已保存凭据就不发任何请求；
    - 有凭据才复用现有 `SavedAccountLoginService`（Load → SetCredentials → Login）；
    - 失败只记异常类型名，不弹框、不改界面错误文字；
  - `OnLoaded` 改为：插件设置与自动登录并行，等自动登录结束后再查账号状态，避免“状态查询先完成、登录后完成”导致显示未登录。
- `MainWindow.xaml.cs` 的 `ShowMain()`：进入主界面后调用 `_settingsPage.EnsureAutoLoginAsync()`。
- 第一次登录仍然通过「保存并登录」保存凭据（原有逻辑），因此下次启动即可自动登录。
- 手动登出仍保留已保存凭据；按用户确认，下次启动仍会自动登录。
