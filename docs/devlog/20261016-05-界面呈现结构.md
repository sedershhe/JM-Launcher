# 20261016-05 · 界面呈现结构（对照 PCL2 源码）

## 一、任务

用户要求补充"计划界面呈现目录"，并明确指定：
**不确定实现形式时必须参考 PCL2 源码仓库 `D:\vscode\Project\PCLUI\PCL-main`，不要自由发挥。**

用户描述的期望结构：
- 主程序自有功能 → 窗口上方切换按钮
- 插件功能总按钮 → 窗口上方
- 切进插件后 → 左侧栏显示二级目录（插件管理 / 插件功能）
- 默认右侧显示插件管理
- 点「插件功能」→ 右侧变为已启动插件列表
- 点某插件 → 进入该插件功能页

## 二、PCL2 源码实测结果

### 2.1 三层骨架（FormMain.xaml）

| 区域 | 源码元素 | 位置 |
| --- | --- | --- |
| 顶部导航 | `PanTitle`（高 48）+ `PanTitleSelect` | `:100` / `:120` |
| 左侧栏 | `PanMainLeft` | `:164` |
| 右侧内容 | `PanMainRight` | `:160` |
| 内页标题栏 | `PanTitleInner` + `LabTitleInner` | `:133` / `:136` |

### 2.2 关键机制

**左侧栏与右侧内容成对整体替换**（`FormMain.xaml.vb`）：
- `:1508` `PanMainLeft.Child = PageLeft`
- `:1527` `PanMainRight.Child = PageRight`

即切换一级页面时左右两栏一起换。

**一级导航**（`:121~130`）：一组 `MyRadioButton`，
`Text` 为「启动」「下载」「联机」「设置」「更多」，各带矢量 Logo。

**左侧栏形态**（以 `Pages/PageDownload/PageDownloadLeft.xaml` 为例）：
`MyListItem` 单选列表（`Type="RadioBox"`），每项 `Height="36"`、带图标与标题；
中间可插分组标题（`<TextBlock Text="社区资源" Opacity="0.6" FontSize="12" />`）。

**内页进入/返回**：
- 进入子页面：顶部主导航淡出，`PanTitleInner` 淡入（显示返回按钮 + 页面名），
  见 `:1422~1434`
- 返回：`PageBack()` 从 `PageStack` 弹出上一层，见 `:1381~1387`

## 三、JML 采用的界面结构

```
顶部（高 48，PCL2 同款渐变）
  [JML 文字Logo]  下载 | 搜索 | 插件 | 设置
────────────────────────────────────
左侧二级目录   │  右侧内容
（仅「插件」页） │
  插件管理     │ [默认] 插件管理界面
  插件功能     │ → 已启用插件列表 → 某插件功能页（内页，可返回）
```

规则要点：

1. 下载、搜索、设置为顶部一级按钮；下载/搜索无左侧栏（右侧全页）
2. 「插件」进入两栏模式，左侧两项：插件管理（默认）、插件功能
3. 插件功能列表只列**已启用**插件
4. 进入插件功能页沿用 PCL2 内页机制（顶部变「返回 + 插件名」）
5. 同一一级页内点二级项只换右侧；切一级页时左右一起换（套用 PCL2 成对机制）

## 四、一个必须提前说明的约束

PCL2 使用**自定义控件**：`MyListItem`、`MyPageLeft`、`MyRadioButton`、
`MyIconButton`、`MyScrollViewer` 等（定义在 PCL2 源码内部，
`MyListItem` 支持 `Type="RadioBox"` 与内嵌 `Buttons` 按钮组）。

本项目使用的 `PlainToolkit.UI` 实测只有**标准 WPF 控件的样式**（21 个）：
Button、CheckBox、RadioButton、Slider、ComboBox、TextBox、PasswordBox、
ScrollBar、ContextMenu、ToolTip、ListBox、ListView、DataGrid、TabControl、
Card、ToggleButton、ScrollViewer、Window、Label、TextBlock、Menu/MenuItem、
TreeView、Expander、GroupBox、StatusBar
——**不含** `MyListItem` / `MyPageLeft` / `MyIconButton`。

**结论**：界面**结构**照 PCL2 还原，具体控件需用标准控件 + 本库样式组合实现，
或按需补一个列表项控件。属实现细节，留待技术方案阶段。
