# 收藏夹与插件列表改为 PCL2 资源行（2026-10-19）

## 目标

按用户提供的 PCL2 Mod / 整合包搜索区截图，把三处列表改成同一套「PCL2 资源行」：

1. 收藏夹的收藏漫画概览；
2. 插件功能列表；
3. 插件管理列表。

用户确认的三点：

- 收藏封面用 **44×58 竖版**（行高仍 64）；
- 插件功能 / 插件管理没有封面，统一用 **JML 蓝色六边形 logo** 占位；
- 下载历史也走同一个 `list` 模板，**一起改**成新样式。

## 视觉参数（来源：PCL-main MyResourceItem.xaml）

| 项目 | 值 |
| --- | --- |
| 行高 | 64 |
| 左侧留白 / 封面 / 间隙 | 7 / 44×58（圆角 6）/ 8 |
| 标题 | 14px，ColorBrush1，单行省略 |
| 副标题 | 12px，ColorBrushGray1，40% 不透明度 |
| 标签 | 11px，`#868686` 字，`#11000000` 底，圆角 3，padding 3,1 |
| 描述 | 12px，ColorBrushGray3，与标签同行，右侧省略 |
| 底部信息行 | 11px 图标 + 12px ColorBrushGray4（时间 / 编号 / 来源） |
| 悬停 | ColorBrush7 底 + ColorBrush6 边框，圆角 3 |

## 实现

- 新增 `Controls/JmlResourceRow.cs`：
  - `JmlResourceMetaItem`、`JmlResourceAction`、`JmlDelegateCommand`；
  - `JmlResourceIcons`（版本 / 下载 / 时间 / 来源四条 Geometry，路径数据取自 PCL2）。
- `Controls/JmlControls.xaml`：
  - 新增 `JmlResourceLogo`（80px 解码的 JML logo 资源）；
  - 新增 `JmlResourceRowTemplate`，三处列表共用。
- `Pages/PluginPageHost.xaml(.cs)`：
  - `list` 模板的 DataGrid 改为单列资源行（无表头、行高 64）；
  - 收藏夹行显示封面；下载历史等没有 `thumb_book_id` 的行显示 JML logo；
  - 行内按钮从独立列移到模板内部，通过 `ICommand` 继续回传原始行；
  - 列表与分页分别套 `JmlCard`；筛选栏套一张紧凑卡片。
- `Pages/PluginFeaturesView.xaml(.cs)`：
  - 插件列表与多页面选择列表都改用 `JmlResourceRowTemplate`；
  - 显示插件名、功能页数量标签、页面清单、插件 ID。
- `Pages/PluginListView.xaml(.cs)`：
  - 管理列表改为单列资源行（无表头、行高 64）；
  - 显示插件名、版本副标题、状态标签、说明、插件 ID；下方启用/停用/重新扫描按钮不变。
- `JML.csproj`：把 `Assets/JML_logo_20261018_v1.0.png` 作为 WPF Resource 嵌入。
- `JML.Tests`：同步更新资源行结构相关的断言（列数、行高、行内按钮数量）。
