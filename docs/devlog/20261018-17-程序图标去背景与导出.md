## 一、抠图

- **不能按颜色删白**（主体内部白色 JML 会被一起删掉）；
- 实际做法：四边框带聚类出棋盘两色 → 背景候选（低彩度 + 近参考色）→ **连通域 + 只保留与四条边相连的背景域** → 取反得前景 → **最大连通主体**保留（99.42%）→ 剔除 77 个区域（水印 5 个字形域 + 72 个噪点）→ 内部白字强制不透明；
- 边缘 1px 羽化（腐蚀 + 高斯 + 阈值重映射），过渡带落在实心蓝内部，深色背景无白边；
- 裁切为正方形并留 3% 透明边距。

## 二、图标

- `Assets/icon.ico`：**10 帧**（16/20/24/32/40/48/64/96/128 BMP + 256 PNG），全部 32bpp 带 alpha；
- ≤32 小尺寸单独处理（2× LANCZOS → 压细边 → BOX → 锐化/提亮），避免小图糊成青色光晕；
- 源图保留：`Assets/JML_logo_20261018_v1.0.png`（1024 RGBA），供以后再导出；
- 用户原始文件 `JML.png` 未修改、未移动、未删除。

## 三、接入与验证

- `JML.csproj`：`ApplicationIcon` 与 `<Resource>` 均指向 `Assets/icon.ico`（只更新了过时注释）；
- `MainWindow.xaml`：`Icon="pack://application:,,,/JML;component/Assets/icon.ico"` 有效，资源内含该条目且 WPF 解码器可读出 10 帧；
- 从 `JML.exe` 反向抽取图标与 ico 的 48 帧逐像素一致（最大差 0），确认不是旧 PCL 图标；
- 预览：`Draw/icon-preview/preview.png`（白底/深底并排 16~256）；16px 只能保留蓝色徽章轮廓（每字母约 3px，属物理极限），32px 可辨 J-M-L 三段。
