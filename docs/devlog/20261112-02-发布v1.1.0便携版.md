# 20261112-02 发布 v1.1.0 便携版（新增强化搜索插件）

## 起因

强化搜索插件（P1–P6 + UI 修复）已验收通过并合入主干，需要按项目发布流程更新发行版，压缩包命名与上一代保持一致（`JM_Launcher.zip`），并在 GitHub 发新 Release。

## 版本号

`JML.csproj` 的 `Version` / `FileVersion` 从 `1.0.0` 提升到 `1.1.0`（新增功能、向后兼容，取次版本号）。Git tag 用 `v1.1.0`，与上一代 `v1.0.0` 风格一致。

## 打包

用仓库自带脚本 `scripts/publish-portable.ps1 -Version 1.1.0`：

- `dotnet publish`（Release、win-x64、框架依赖）输出到 `dist/JML-portable-1.1.0-20261112/`；
- 复制 Python 源码（排除 tests/`__pycache__`）与全部 5 个插件；
- 生成 `README.txt`（运行要求、数据目录、SmartScreen、自检命令、插件清单）；
- 脚本自带校验：必需文件齐全、无用户数据/日志/temp/`bin`/`obj`/`.git`；
- `Compress-Archive` 生成 `JML-portable-1.1.0-20261112.zip`，另复制一份为 `JM_Launcher.zip`（与 v1.0.0 资产同名）。

上一代 `dist/JML-portable-1.0.0-20261019/` 已先移到 `Delete/dist-backup-20261112/` 备份，避免被脚本的自身清理逻辑删除。

## 验证

- 包内插件：`advanced_search`、`download_history`、`favorites`、`zip_browser`、`zip_web`（5 个）。
- 包内文件数 85，压缩包 1.86 MB。
- 发布包自检：`JML.exe --selfcheck` 退出码 **0**（Python 运行时、依赖库、插件扫描/装配、服务注册表、配置契约全部通过）。
- 代码测试沿用上一轮结果：Python 664 passed、C# 253 passed。

## 发布

- Git：提交版本号与本文档，打 tag `v1.1.0`，推送 `master` 与 tag。
- GitHub Release：`v1.1.0`，标题 `JM Launcher v1.1.0（20261112 便携版）`，资产 `JM_Launcher.zip`，简介简要说明强化搜索插件的功能。

## 说明

- 发布包为框架依赖版，用户需安装 .NET 10 桌面运行时与 Python 依赖（与 v1.0.0 一致）。
- `dist/` 与 `Delete/` 均在 `.gitignore` 中，发布产物不入库。
