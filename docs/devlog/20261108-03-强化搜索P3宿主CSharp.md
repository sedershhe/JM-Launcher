## 关键语义（与 list 相反，已按协议实现）

- **改下拉只暂存**：`OnSearchFilterChanged` 只写 `_searchFilterValues`，不触发加载。
- **提交**：点「搜索」或回车，组 `{page, keyword, 所有 filter key:value}` 存进 `_searchCommitted` 再加载。
- **翻页**：复制 `_searchCommitted` 只改 page，用户改了输入框但没提交时翻页仍用旧值。
- **回填**：`RenderSearch` 用 Python 返回的 `search_box.value` 与 `filters[].value` 覆盖控件，C# 不自己记忆。
- **能力置灰**：`capabilities.time/category/sub_category` 为 false 时 `IsEnabled=false` + `ToolTip`（`ToolTipService.SetShowOnDisabled`）。
- **重置**：清空关键词与暂存，提交 `{page:1}`。

## 与方案不一致（已确认可接受）

1. 结果区不固定 `RowHeight=96`（80×110 封面会被裁 14px），改自适应 + 行模板 `MinHeight=96`。
2. 分页隐藏条件比方案保守：`total_pages==0 && total==0 && rows==0` 才隐藏。
3. placeholder 用覆盖 TextBlock（不用 ToolTip）。
4. 箭头收起 0°/展开 180°，与方案「展开向上」视觉等价。
5. `JmlCollapse` 资源在页面 `UserControl.Resources` 合并，不动全局 `JmlControls.xaml`。
