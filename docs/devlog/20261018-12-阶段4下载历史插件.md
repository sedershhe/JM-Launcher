## 一、插件实现

| 文件 | 内容 |
|---|---|
| `plugins/download_history/plugin.json` | `id=download_history`、`api_version=1`、1 个 `list` 模板页面、配置 schema |
| `config.schema.json` | `keep_count`（integer，默认 200，10~10000） |
| `main.py` | 订阅 `download.item_finished` 记录 `{time, book_id, title, ok, zip_path, error_code}`；`register_page` 输出 list payload（时间/本子号/结果/输出路径）；按 `keep_count` 裁剪；分页 |

```json
  "columns":[{"key":"time","title":"时间","width":200},{"key":"book_id","title":"本子号","width":120},

  "rows":[{"time":"2026-10-18T13:50:25+08:00","book_id":"422222","result":"成功","path":".../xxx-JM422222.zip"}],
  "page":1,"page_size":50,"total":2,"total_pages":1,"row_actions":[],"empty_text":"暂无下载记录"}}
```

## 二、落盘与健壮性

- 路径：`%APPDATA%\JML\plugins\download_history\data\history.json`（由宿主传入的数据目录，插件不拼路径）；
- 内容：`{"version":1,"records":[...]}`，**白名单字段**，凭据一律不落；
- 写入：每条即落，`tmp` + `os.replace` 原子替换；`batch_finished` 只做兜底裁剪；
- 损坏恢复：懒加载捕获 `OSError/ValueError/TypeError` → 写诊断、清空内存并重建空文件，不向宿主抛异常；
- 取消的单条按 `item_finished(ok=false, CANCELLED)` 记为"失败"，与计划书 4.4 口径一致。
