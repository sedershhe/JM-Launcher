## 实现要点

- 探测内核纯函数化：`fetch` 由 `main.py` 注入（`curl_cffi` 惰性 import），单测注入假函数；不联网也能测。
- 重定向规则复刻 jmcomic：301 继续、302 收口取 `Location`（`stop_on_302=True`，永久网域）；发布页 `stop_on_302=False` 跟到 200；`Location` 用 `urljoin` 补相对路径；最多 4 跳。
- 只读红线：不调用 `get_html_domain()` / `get_html_domain_all()`，不读写 `DOMAIN_HTML` / `DOMAIN_HTML_LIST`，不 import `jml.core.jm_source`，不写 `ctx.config_set` / `ctx.data_dir`；只读 `JmModuleConfig` 的 `DEFAULT_PROXIES` / `JM_REDIRECT_URL` / `JM_PUB_URL`。
- 并发：`ThreadPoolExecutor(max_workers=4)`，手动 `shutdown(wait=False, cancel_futures=True)`；总预算 28 秒，到点未完成记为 `pending`；`redirect_target` 在入口链完成后追加。
- 判定：`ok` / `restricted` / `fail` / `pending` 四值，界面 `result` 映射"可用 / 受限 / 不可用 / 未完成"；正文特征优先于状态码（Cloudflare 挑战页常为 403/503，只匹配 200 会失效）。
- 候选来源默认只接前 3 行（永久网域入口、发布页入口、3 个静态兜底），第 4/5 行（jmcomic 缓存）按 §8 红线**不实现读取**，避免假域名。
