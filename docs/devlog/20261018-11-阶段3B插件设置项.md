## 一、Python 侧

| 项 | 实现 |
|---|---|
| 入口 | `list_plugin_settings()` / `set_plugin_setting(plugin_id, key, value_json)`，全 JSON 字符串、失败收口 |
| schema 枚举 | `config.describe_schema()` + `_ui_type()` + `is_password_field()` + `validate()`（复用阶段 1 的配置契约，没有另起一套） |
| 插件快照 | `loader.loaded_plugins()` / `config_for()`，复用插件 setup 期间同一个 `PluginConfig` 实例 |
| 校验 | 类型（integer 排除 bool）、enum、min/max、未知 key；非法写入**不改进程内存、不碰 config.json**；schema 自身写错在加载阶段就报 `ConfigError` |
| 落盘 | `%APPDATA%\JML\plugins\{id}\config.json`（经既有路径推导，未硬编码） |
| 类型映射 | 显式 `ui` 优先（text/password/number/bool/select/path）；否则 enum→select、string→text、integer/number→number、boolean→bool；label 取 `label→title→key` |

## 二、C# 侧

| 项 | 实现 |
|---|---|
| Bridge | `PluginSettingsBridge`（`ListAsync`/`SetAsync` + `IPluginSettingsGateway` 便于离线测试）；DTO 全 snake_case，`default/value` 用 `JsonElement` 保留标量类型 |
| 设置页 | 「插件设置」卡片按插件分组动态渲染：text/path→TextBox（path 带「浏览…」）、number、bool→CheckBox、select→ComboBox、password→PasswordBox；失焦/勾选/下拉变更或点「保存」提交；失败只在项下红字显示 `[error_code] error_message`，界面值保留 |
| 交互 | 加载时与账号状态异步并行拉取，不阻塞 UI；未改动字段跳过写盘 |
| 样式 | 只新增 `JmlPasswordBox`（与 `JmlInputBox` 同源），其余复用 `JmlCard`/`SecondaryButton`/`JmlInputBox` |

## 三、安全（本阶段重点）

- **password 类型设置项**：schema 禁止非空 `default`；值只存在 Python 进程内存，`config.json` **永不出现** password 键；`list`/`set` 只回空串 + `has_value`；校验失败文案固定为"password 设置值不合法（出于安全不回显具体值）"；
- C# 密码框**不回填**、成功后立即清空、类内无密码字段；
- 测试直接断言：返回文本与 `config.json` 全文都不含明文 secret；写入位置在隔离 APPDATA 的 `JML/plugins/{id}/config.json`；
- **已知边界**：password 类型的跨重启持久化按"配置不含凭据"红线不实现，将来需要时接 C# 凭据管理器/DPAPI。
