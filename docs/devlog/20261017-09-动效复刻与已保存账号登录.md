## 一、已保存账号登录（阶段 3 补漏）

**问题**：凭据存在 Windows 凭据管理器/DPAPI 里，但 Python 侧凭据只在内存，重启后为空；原窗口只有"保存并登录"（需重输密码）→ **重启后等于不能用**。

**修法**：
- 账号窗口与设置页新增「使用已保存账号登录」（仅存在保存凭据时可用）；
- 固定链路：`CredentialStore.Load() → SetCredentials(u,p) → Login()`；
- **启动时不自动登录**（避免无谓网络与失败弹框），由用户或后续插件按需触发；
- 密码只在方法局部变量短暂存在，取用后立即置空，不写入任何字段（反射测试断言类中无 string 密码字段）；失败文案先用本次账号/密码字面打码再过 `LogSanitizer`。

## 二、动效（按 PCL2 源码参数）

规格文档：`docs\20261017_PCL2动效规格_v1.0.md`（832 行，63 条 file:line 参数 + 缓动对应 + "不要做"清单）。

**关键前提**：PCL2 用自研逐帧增量引擎，"同属性两条并行动画会相加"；WPF Storyboard 是覆盖。所以复合动效一律**按 10ms 采样合并成一条关键帧动画**（如页面入场的 `+5/250ms` 与 `+11/350ms` 叠加），禁止直接叠两条 `DoubleAnimation`。

| # | 动效 | 实现 |
|---|---|---|
| 1 | 窗口入场 | 内容层 `Y 60→0 / 600ms / 延迟100 / EaseOutBack(峰值1.177)`、`旋转 -4°→0 / 500ms`、`Window.Opacity 0→1 / 250ms`；结束清动画、位移归零、无 Effect；不碰 `Window.Top/Left` |
| 2 | 页面切换（一级页与插件内页共用） | 新内容 `Opacity 0→1 / 100ms` + `Y -16→0`（36 帧采样、350ms）；旧内容整层 `1→0 / 70ms` 后换页（简化项，PCL2 是逐控件 stagger）；可重入：每次先 Stop 旧动画 + 归零，generation 守卫防旧回调覆盖 |
| 3 | 内页标题栏 | 进入：主层淡出+`X 0→12/150ms`、内层延迟 200ms 淡入 + `X -16→0/350ms`；返回镜像；总 550ms |
| 4 | 导航胶囊 | 悬停 90 / 移出 150 / 按下 60 / 选中 120ms；**悬停底色修正为 PCL2 的 `#32EAF2FE`**（原先错写 `#32FFFFFF`）；无缩放 |
| 5 | 左栏列表项 | 悬停 120 / 出 180、按下 120；选中条 Opacity 200ms + ScaleY 300ms |
| 6 | 图标按钮 | 悬停 120/150；按下 `1→0.8/400ms PowerEase(4)`；抬起 250ms 采样回弹（峰值 ≈1.039） |
| 7 | 卡片 | 悬停 90ms：标题色 `ColorBrush1→2`、独立阴影层 Opacity `0→0.33`（叠加常态 0.07 ≈ 0.40）；**不动 `DropShadowEffect.Opacity`**（会掉帧） |
| 8 | 加载指示 | 搜索结果区 PCL2 风格"挥镐"（动画区 60×47、周期 2.58s）；结束时 Remove 并复位，无残留 |

### 简化项（已记录，后续按需补）

1. 旧内容退出用整层 70ms 淡出，未做 PCL2 的逐控件 stagger（右栏 70ms/项、左栏按控件数分摊）；
2. 插件页左栏宽度固定 160，无 180ms 宽度动画；
3. 导航选中白底仍是触发器瞬切（旧测试断言"选中即纯白"，改动画需同步改断言）；
4. 次按钮悬停沿用外部库模板的 100/120ms（PCL2 为 100/200）；
5. 选中条颜色过渡用浅色 Tint 淡出表达，未直接动画共享主题画刷（避免全局污染）；
6. 详情窗未加挥镐指示；卡片折叠/高度补间未做（无折叠功能）。
