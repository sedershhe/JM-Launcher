## 三、环境调试：Python 改为用户自装

### 变更背景

前一版环境默认本机已装 Python（`D:\python`）。用户明确要求改为**由用户自行安装**，
因此程序不能再假设 Python 一定存在，必须能自检并引导用户。

### 具体改动

| # | 改动 | 说明 |
| --- | --- | --- |
| 1 | 移除注释中的具体路径 | `PythonRuntime.cs` 注释里原写了具体盘符路径，改为"由用户自行安装，只能靠探测" |
| 2 | 新增 `PythonEnvironmentReport` | 承载检测结果：Python 版本、已装依赖、缺失依赖、问题、处理办法 |
| 3 | 新增 `PythonRuntime.Inspect()` | 三步实测：能否定位运行时 → 版本是否合规 → 依赖库是否齐全 |
| 4 | 检测失败给出可执行指引 | 未装 Python 时提示去 python.org 装 3.13 并勾选 Add to PATH；依赖缺失时提示执行 `pip install -r requirements.txt` |
| 5 | `requirements.txt` 补安装步骤 | 写明 Python 下载来源、版本要求、安装命令、`JML_PYTHON_HOME` 用法 |

### 设计要点

- **不做猜测，逐项实测**：能报出"缺哪个库"，而不是笼统报错。
- **不硬编码路径**：Python 位置靠探测（环境变量 → PATH → 常见位置 → 注册表）。
- **异常描述脱敏**：`Inspect()` 里的错误文本经 `LogSanitizer` 处理，避免凭据外泄。
