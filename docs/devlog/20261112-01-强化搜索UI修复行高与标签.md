# 20261112-01 强化搜索 UI 修复：行高、标签、镐子颜色与水印

## 起因

P6 交付后用户手工验收，陆续报了 5 个界面问题：筛选下拉不在高级折叠区里、条目右侧两根线、加载镐子颜色不对、输入框水印与光标重叠、结果行内容被裁一半。最后一轮按用户要求把条目标签整体去掉。

## 逐项处理

### 1. 筛选下拉挤在折叠区外面（P6 已修）

`Pages/PluginPageHost.xaml` 原先把筛选下拉放在独立的 `CardSearchFilters` 卡片里（折叠面板上方），5 个下拉横向排列、窗口一窄就溢出。改为全部放进 `SearchAdvanced` 折叠区，容器用 `WrapPanel`，每组「标签 + 下拉」150 宽自动换行；翻页保留用户展开状态（`_searchAdvancedInitialised` 只初始化一次）。

### 2. 结果行被压扁（本轮根因修复）

现象：封面、标题、标签都只显示一半。

根因：`Controls/JmlControls.xaml:696` 的共享样式 `JmlDataGrid` 把 `RowHeight` 固定为 36；`GridSearchRows` 没有覆盖，行模板的 `MinHeight` 赢不过 DataGrid 行高，内容被垂直裁掉。

修复：`GridSearchRows` 显式 `RowHeight="126"`（封面 110 + 上下 padding 8+8），行模板 `MinHeight` 同步 96 → 126，并补测试 `SearchTemplate_RowHeightLeavesRoomForCover` 断言行高 ≥ 110。list 模板（64）与共享样式（36）未动。

### 3. 条目右侧两条线

那是行内「详情 / 下载」按钮的 1px 深色边框：按钮用 `SecondaryButton`，浅色行上只剩两条线、文字被挤没。改为 search 专用的无边框文字按钮 `JmlSearchRowActionButton`：透明底、12px 灰字、悬停变 `ColorBrush2`（主题蓝）。

### 4. 挥镐动画换蓝色

`Controls/JmlLoadingPickaxe.xaml` 的默认 `Foreground` 从 `ColorBrush1` 改为 `ColorBrush2`，镐子、碎屑、底部进度条一起变蓝。

### 5. 输入框水印与光标重叠

水印层一直显示，和输入光标叠在同一位置。改为**聚焦时隐藏**、失焦且为空时才显示（`SearchBox_FocusChanged` + `UpdateSearchPlaceholder`）。

### 6. 标题里的 HTML 实体

截图里标题出现 `&amp;#160;`，是网页标题双重转义。Python 侧新增 `_decode_html_text`，最多循环 `html.unescape` 三次解到稳定；`_search_row` 的标题、作者、标签都过一遍（`jm_source.py:505-532`）。

### 7. 标签最终去掉

标签先从小标签改成右侧竖排小字，用户复看后要求删除。`JmlSearchRowTemplate` 右列现在只保留「详情 / 下载」两个文字按钮，标签的 `ItemsControl` 整块移除。C# 的 `Tags` / `explicitTags` 计算保留（list 模板仍在用，search 不再显示）。
