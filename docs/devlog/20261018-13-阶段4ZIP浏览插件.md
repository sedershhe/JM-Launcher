## 三、`archive_reader/1` 服务

```
list_images(zip_path) -> [entry_name, ...]    # 自然排序；未打开则打开
read_image(zip_path, index) -> bytes          # 越界抛「页码超出范围」，未打开抛「压缩包已关闭」
close(zip_path)                               # 幂等
is_open(zip_path) -> bool
```

- 单把 `RLock`；打开/筛选与 `ZipFile.read` 都在锁内；`close` 先摘字典再关句柄；
- 对象字段只有 `_lock/_archives/_entries`，**不暴露 ctx/registry/bus**（测试断言）；
- 契约 §六 补方法表；注：该服务没有统一 `call()`，消费方用 `ctx.get_service` 直调（图片是 bytes）。
