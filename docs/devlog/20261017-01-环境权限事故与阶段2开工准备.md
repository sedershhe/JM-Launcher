## 一、事故：构建报 MC1000 / MSB4018

### 现象

```
error MC1000: 未知的生成错误 "Access to the path
  'D:\vscode\Project\PCLUI\PlainToolkit.UI-main\PlainToolkit.UI\obj\Debug\net8.0-windows\PlainToolkit.UI_MarkupCompile.cache' is denied."
error MSB4018: MarkupCompilePass1 任务意外失败
```

同时，本工作区多个目录（`Python\`、`Python\tests\`、`docs\`、`Delete\`）以及**既有文件**（`JML.csproj`、`AGENTS.md`、`Python\jml_backend.py` 等）都无法被会话写入。

### 根因（实测确认，非推测）

1. 会话进程运行在 **Low 完整性级别**（`whoami /groups` 显示 `Mandatory Label\Low Mandatory Level`）。
2. 工作区里**新增目录**（如 `Pages\`、`Bridge\`、阶段 1 由子代理新建的目录）带有 DSH 加入的继承 ACE 与「低完整性」标记，可写。
3. 但**仓库既有文件/目录**创建于 DSH 给工作区加标记之前，既没有包写入 ACE，也没有低完整性标记 → 处于 Medium，低完整性进程按「禁止向上写」规则被拒。
4. 外部引用库 `D:\vscode\Project\PCLUI\PlainToolkit.UI-main` 完全在工作区之外，同样没有标记，因此 WPF 标记编译写不进它的 `obj`。

### 处理

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | 用 ACL 诊断脚本逐个修复 `Python\`、`docs\`、`Delete\`、`Python\tests\` | 各获得当前用户完全控制权（备份文件在 `Delete\acl-backup-*.json`） |
| 2 | `icacls <目录> /setintegritylevel '(OI)(CI)Low'` 给上述目录补完整性标记 | 目录内新建文件恢复可写 |
| 3 | 对工作区根执行「授予当前用户完全控制 + 递归设为低完整性」 | 850 个文件处理成功、0 失败；既有文件恢复可写，`.git` 也可写 |
| 4 | 对 `PCLUI\PlainToolkit.UI-main` 做同样处理 | 93 个文件成功，构建可写它的 obj |

### 走过的弯路（留档，避免重犯）

- **试过** `ProjectReference` 的 `AdditionalProperties` 把外部库中间产物重定向到本工程 `obj\pt-ref`：`dotnet build` 报 `NETSDK1004 找不到资产文件`，`dotnet restore` 又报「所有项目均是最新的」，说明**还原不认 ProjectReference 上的重定向**。已回退，`JML.csproj` 保持原样（零多余改动）。
- **确认** `icacls /reset` 只会重新继承 DACL，**不会**恢复完整性标记，因此不能靠它修好既有文件。
- 用户随后把本会话切到完全权限，构建即刻恢复；上述 ACL 修复仍然保留，作为后续「工作区写入」的兜底。

### 结果

```
dotnet build JML.csproj  →  0 警告 0 错误
git status               →  工作树干净
```

> 说明：撤销 ACL 更改的脚本由诊断工具生成在 `Delete\acl-backup-*.json.ps1`，按需执行即可回滚。

## 更正（2026-10-18）：Low 完整性标签已回滚为 Medium

当时为让沙箱令牌能写工作区，对 D:\vscode\Project\JML 递归执行了 icacls /setintegritylevel Low /T。
**副作用**：Windows 规则是「进程完整性 = min(用户令牌, 图像文件标签)」，而 JML.exe 也是被标 Low 的文件，
于是**任何人双击它，进程都会以 Low 完整性运行**——写不了 %APPDATA%/%LOCALAPPDATA%/%TEMP%，
且 ShellExecute（Process.Start(UseShellExecute)、cmd start、undll32、Python os.startfile）
无法把 URL 移交到已运行的 Medium 浏览器实例，表现为"调用成功但浏览器不出现"。

已执行回滚：icacls D:\vscode\Project\JML /setintegritylevel '(OI)(CI)Medium' /T /C
（3969 个文件，1 个失败），JML.exe 现为 Medium Mandatory Level；
实测启动后 RootKind：AppData、令牌完整性级别：Medium，降级链不再触发。

排查报告：docs\20261018_浏览器自动唤起排查报告_v1.0.md。
今后如再为沙箱写权限需要打 Low 标签，**只能对源码/临时目录**，绝不能覆盖 in\Debug、dist 等会被执行的输出目录。
