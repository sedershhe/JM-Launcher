## 1. 标题栏蓝色不够还原 → 改用 PCL2 真实算法

- **根因**：JML 先抄了 PCL2 **XAML 默认值** `#4890F5`（`FormMain.xaml:101-105`），但 PCL2 **运行时**用 `MyColor.FromHSL2` 重算覆盖（`ModSecret.vb:114-120`）。
- **关键**：`FromHSL2` 不是普通 HSL，它带**按色相的亮度校正**（`ModBase.vb:365-386`，14 段 `cent` 表）。按它实算：`HSL2(210,85,48)` = **#106AC4**，`HSL2(210,85,54)` = **#1277DD**；普通 HSL 得到的 #127AE2/#268AED 是**错的近似**。
- **实现**：新增 `Infrastructure\PclThemeColor.cs`（`FromHsl2` + `FromHsl` + `CreateTitleBarBrush`），标题栏渐变在构造函数里生成三停靠 `#106AC4 → #1277DD → #106AC4`；XAML 不再写死色值。
- **验证**：截图三点采样左 `#106AC4`、中 `#1277DD`、右 `#106AC4`（`Draw\ui-fix-shots\07-titlebar-hsl2.png`）。

## 2. 切页时半透明内容压到标题栏 → 裁剪 + 层级

- **根因**：`MainContent` 未裁剪，页面入场 `Y -16→0` 会画到标题栏区域；且标题栏在 XAML 中声明在前、Z 序更低。
- **PCL2 的等价做法**：页面滑动被内容容器（ScrollViewer）裁剪，不会盖住标题栏。
- **实现**：内容区外包 `Border ClipToBounds="True"`；标题栏 `Panel.ZIndex="10"`；`x:Name="MainContent"` 与代码零改动。
- **验证**：切「下载→插件」时于 91ms / 214ms 截图，标题栏底部空白带异常像素 **0.00%**，平均色与静止态一致；插件页左栏顶部被正确裁在标题栏下沿。

## 3. 部分按钮文字与背景融合

- **主因**：外部库 `PlainToolkit` 的**隐式 TextBlock 样式**把 `Foreground` 固定为 `ColorBrush1`，压过按钮前景 → 主按钮实际是 `#343D4A` on `#1370F3`，对比度仅 **2.43:1**。
- **修法**：
  | 项 | 改动 | 对比度 |
  |---|---|---|
  | 主按钮文字 | 模板改显式 `TextBlock` + `TemplateBinding Foreground` → `ColorBrush8` | 2.43 → **4.02:1** |
  | 主按钮悬停底 | PCL2 原值 `#4890F5` 与浅色字只有 2.83 → 改 `ColorBrush2 #0B5BCB`（同套调色板） | **5.52:1** |
  | 次按钮禁用 | 复制模板进 JML（不改库），文字 `Gray3` | 2.04 → **2.82:1** |
  | `PythonSetupPage` 按钮 | 补隐式按钮样式（35 高 / 13px） | 合格 |
  | 侧栏选中文字 | 模板改显式 `TextBlock` + `TemplateBinding Foreground` → `ColorBrush3` | 修复"选中不变蓝" |
- **全仓审计**：25 个按钮逐条列样式/字号/前景/背景/对比度（见 `Draw\ui-fix-shots\capture-log.txt` 与报告）。
