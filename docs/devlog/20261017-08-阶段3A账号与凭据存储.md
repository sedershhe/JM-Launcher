### jmcomic 2.7.1 登录查证（重要，写代码前必须先查）

- 默认客户端是 API：`jm_config.py:471` `DEFAULT_CLIENT_IMPL='api'`；登录入口 `JmApiClient.login(username, password)`（`jm_client_impl.py:802-838`），内部 `req_api('/login', False, ...)`，默认 `require_success=True`。
- 失败判定：`JmApiResp.is_success` 要求 HTTP 成功且 JSON `code==200`（`jm_client_interface.py:113-114`），否则抛 `ResponseUnexpectedException`（`jm_exception.py:137-147`）。
- 登录成功只把 cookies 写进**内存** postman 元数据（`jm_client_impl.py:834-836`），不落文件。
- **坑**：`JmApiClient.login` 不设置 `client._username`，且**匿名会话也带 AVS cookie** → **不能用 cookie 或 `_username` 判断登录态**，必须用显式 `_logged_in` 标记。已加测试 `test_source_login_anonymous_avs_is_not_login_proof` 锁死。

## 二、C# 凭据存储

| 项 | 实现 |
|---|---|
| 首选 | Windows 凭据管理器，P/Invoke `CredWriteW/CredReadW/CredDeleteW`，`CRED_TYPE_GENERIC`，目标名 `JML/jm-account`，`CRED_PERSIST_LOCAL_MACHINE` |
| 回退 | DPAPI `ProtectedData.Protect(..., CurrentUser)` + 固定熵，密文写 `%APPDATA%\JML\account.dat`（经 `AppPaths`），**临时文件原子替换** |
| 双失败 | `Save` 返回 false，`LastError` 固定中文提示，**绝不落明文** |
| 互斥清理 | 凭据管理器写入成功则清旧 DPAPI 文件；DPAPI 成功则尽力清旧 CM 条目（避免两处残留不一致） |
| 安全自证 | `CredentialStore` 不写日志、不引用 `AppSettings`、`ToString()` 只输出"凭据已隐藏"；DPAPI 测试用 UTF-8/UTF-16/Latin1 三种视角检查密文**不含**用户名/密码；反射断言 `AppSettings` 无凭据字段 |

## 三、账号窗口与设置页

| 流程 | 行为 |
|---|---|
| 打开（已保存） | 用户名打码 + 密码框留空 + 提示"已保存账号（密码不再显示）" |
| 打开（未保存） | 空表单 + "未保存账号" |
| 保存并登录 | `CredentialStore.Save → SetCredentials → Login`；成功绿字"登录成功：ab***cd"；失败红字 `[error_code] error_message`；成功后清空密码框 |
| 清除已保存账号 | 确认后删 CM + DPAPI + 清 Python 登录态 |
| 登出 | 只清登录态，保留已保存凭据 |
| 取消 | 不改动原凭据 |
| 设置页 | 显示"未登录"/"已登录：ab***cd"；窗口关闭后刷新；下载路径选择后写入 `AppSettings.DownloadDir` |
| 下载页 | 启动时优先用仍存在的记忆目录，否则桌面；浏览/开始下载时回写最终目录 |
