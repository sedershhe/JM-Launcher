## 四、已知取舍（不要当缺陷重报）

- 搜索页：封面 80×110（计划书硬要求），900×550 下完整 2 行；为此内容边距 25→20；
- 页数：jmcomic 2.7.1 把 `page_count` 写死 0，真实值取白名单字段 `total_photos`；搜索按需有界补全（并发 3 / 3s 封顶），补不到的显示 `页数: -`；
- 主按钮统一为次按钮样式（用户要求）；
- 详情窗仍是系统标题栏（PCL2 无独立详情窗）；
- 旧内容切页用整层 70ms 淡出（未做逐控件 stagger）；
- `loader` 仍把插件目录加入 `sys.path`（阶段 4 前应约束为隔离导入，防止插件 import 兄弟插件绕过服务依赖）；
- 启动目录创建失败/临时目录不可写已降级：临时文件改落下载目录，AppPaths 失败只记 `LastFailures` 不阻断启动。

## 五、环境注意

- 构建：`dotnet build JML.csproj -v q --nologo --no-restore -p:BuildProjectReferences=false`（工作区外 UI 库 obj 不可写时用这个参数）；
- 测试：`python -m pytest Python\tests -q`、`dotnet test JML.Tests\JML.Tests.csproj -v q --nologo`；
- **不要**让子代理启动 `JML.exe`（会锁 `bin` 文件导致构建 MSB3027）；需要界面验收时由主代理启动，验收后关闭；
- 用户真实凭据在 Windows 凭据管理器 `JML/jm-account`：**禁止读取/展示/删除**；登录验收只能通过应用界面点「使用已保存账号登录」；
- 临时/证据目录：`Draw\`（临时）、`Delete\`（归档）；`JML.csproj` 已用 `DefaultItemExcludes` 排除这两个目录，防止临时 C# 工程污染构建。
