## 一、本次变更

1. **列表 UI 统一为 PCL2 资源行**
   - 收藏夹收藏漫画概览、插件功能、插件管理三处列表改为与 PCL2 Mod / 整合包搜索区一致的资源行；
   - 行高 64、封面 44×58（收藏夹）或 JML 六边形占位图标（无封面页面）；
   - 标题、副标题、标签、描述、底部信息行（时间 / 编号 / 来源）与行内操作按钮；
   - 下载历史走同一个 `list` 模板，一并改为新样式。
2. **启动自动登录**
   - 第一次通过「保存并登录」成功后，本地已有安全保存的凭据；
   - 后续启动进入主界面时，后台静默执行一次「读取凭据 → 写入 Python → 登录」；
   - 没有已保存凭据时不发请求；登录失败不弹框，设置页仍显示「已保存账号（未登录）」并可手动重试；
   - 按用户确认：手动登出后，已保存凭据仍保留，下次启动仍会自动登录。
3. **主界面默认页改为下载**
   - 进入主界面默认展示下载页，顶部「下载」保持选中；插件页、搜索页、设置页行为不变。

## 三、产物说明

- 便携版是**框架依赖版**，用户仍需安装 .NET 10 桌面运行时、Python 3.11~3.15 并执行
  `python -m pip install -r requirements.txt`；
- 包内 `README.txt` 由发布脚本生成，包含运行要求、数据目录、SmartScreen 与自检命令；
